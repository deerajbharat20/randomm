# PixelNest — Creative Studio Website

A responsive, single-page concept website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, colors, typography and animations/effects
- `script.js` — mobile navigation and dynamic footer year
- `favicon.svg` — browser tab icon

## Run locally
1. Download or extract the project.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded from the web; the site still works with fallback fonts if you are offline.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages section.

## Customize
Search for `PixelNest` in `index.html` to change the studio name and text. Update the email address in the contact section to your own address before publishing.
